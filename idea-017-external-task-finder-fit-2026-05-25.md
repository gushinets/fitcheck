# Идея 17: External Task Finder & Fit

## Мета

## Описание
Фрилансер тратит 3–4 часа в день на оценку вакансий при конверсии 2–5% в найм. Нет инструмента, который за <1 минуты анализирует соответствие конкретной вакансии профилю фрилансера с учётом языковых ограничений. Инструмент читает страницу вакансии и профиль пользователя → выдаёт Fit Score + объяснение + go/no-go на родном языке.

## Бриф идеи
- **Проблема:** Фрилансеры-non-native тратят 3–4 ч/день на просмотр вакансий с конверсией 2–5%, не имея персонализированного фильтра соответствия с языковым анализом
- **Гипотеза:** Non-native фрилансеры на Upwork/Fiverr испытывают боль ежедневного перебора вакансий без fit-анализа и готовы платить $10–30/мес за инструмент, дающий Fit Score за <1 мин
- **ЦА:** Пользователь: non-native англоязычный фрилансер (RU/ES/LATAM/Asia) на Upwork/Fiverr / Покупатель: тот же
- **Целевой формат:** [x] Chrome Extension (нативный вход на странице вакансии Upwork)
- **MVP-функция:** Открыл вакансию → нажал кнопку → получил Fit Score (0–100) + топ-3 strengths/risks + вердикт go/no-go
- **Ограничения:** Требует профиль пользователя (хранится локально при старте); точность зависит от полноты профиля
- **Артефакт:** [x] Нет (внутренний инструмент — score виден только пользователю)

## Контекстный слой
- **Формат продукта:** Chrome Extension
- **Необходимый минимум:**
  - #1 Роль: LLM инферирует при онбординге (фрилансер, специализация, рынок)
  - #2 Цель: явная — оценить соответствие вакансии профилю
  - #3 Рабочий материал: контент страницы вакансии (title + описание + бюджет + клиентский рейтинг) → CONTEXT; профиль фрилансера (skills, rate, experience) → SYSTEM
  - #4 Обратная связь: editable score + объяснение → пользователь корректирует → паттерн
  - #5 Сохранение данных: да — профиль фрилансера, история оценённых вакансий
- **Дополнительные методы:** онбординг-анкета (специализация, желаемая ставка, языковой уровень), история оценённых вакансий в MEMORY, парсинг страницы Upwork/Fiverr
- **Архитектура prompt:**
  - SYSTEM: роль (специализация, ставка, опыт) + языковые ограничения + паттерн правок
  - CONTEXT: полный контент страницы вакансии (title + h1–h3 + description + budget + client info)
  - TASK: "Оцени соответствие этой вакансии моему профилю, дай Fit Score и go/no-go"
  - MEMORY: 10 последних оценённых вакансий (для калибровки)
- **Доступность в Extension:** Полная (страница вакансии полностью читаема)
- **Рекомендуемая форма входа:** Chrome Extension

## Ценность продукта
- **Для пользователя:** Сокращает время оценки вакансии с 15–30 мин до <2 мин; снижает wasteful connects-spending; объясняет языковые риски на родном языке
- **Value proposition:** "Знай за 60 секунд — стоит ли тратить connects на эту вакансию"
- **10× эффект:** Было: 3–4 ч/день ручного просмотра + $1.5–3 connects на слепые ставки → Стало: <30 мин/день на целевые вакансии + Fit Score до трат (≈10×)

### Главный инсайт
Идея закрывает реальную ежедневную боль (3–4 ч/день wasted), но слабый поисковый спрос говорит о том, что пользователи не ищут "fit analyzer" — они ищут "как выиграть на Upwork". Нужен growth through communities (Reddit r/Upwork, Telegram), не SEO. Whitespace по цене ($10–30 vs $400+ у GigRadar) реален, но TAM ограничен соло-фрилансерами, готовыми платить.
